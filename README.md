# Каталог услуг отеля - интерактивный прототип

Кликабельный happy path каталога дополнительных услуг: каталог -> карточка услуги -> корзина -> данные заказчика -> проверка оплаты -> "Услуги забронированы". Без бэкенда, состояние в памяти, данные статикой.

Источник визуала - артборды Design-холста "Каталог услуг - прототип" (8 телефонных и 8 десктопных экранов).

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес из консоли (обычно http://localhost:5173). До 768 px - телефонная компоновка, шире - десктопная.

Другие команды:

- `npm test` - проверки расчёта цены, подписей и валидации формы (node:test, без сборки).
- `npm run build` - typecheck и production-сборка в `dist/`.
- `npm run lint` - oxlint.

## Что прокликать

1. Каталог: чипсы категорий фильтруют сетку, поиск - по названию. На десктопе лента категорий - карусель: стрелки и размытые края появляются только с той стороны, куда ещё есть что скроллить (три последние категории - пустые демо, чтобы лента переполнялась на 1280 px).
2. "+" на карточке или клик по фото открывает карточку услуги: дата, время, специалист, степперы "Продлить услугу" (+1 500 за час) и "Добавить ещё гостей" (+500 за гостя). "Баня на дровах" с продлением на 1 час = 4 500.
3. "Добавить" - услуга в корзине: карточка в состоянии "+ Ещё", на телефоне внизу панель корзины, на десктопе попап "Добавлено в корзину" и кнопка корзины в шапке.
4. Корзина: "Ввести данные" открывает форму заказчика (предзаполнена демо-данными, валидация есть). "Оформить заказ" активна только с заказчиком.
5. "Оформить заказ" -> "Проверяем оплату по заказу № 1234567" (2,5 с) -> "Услуги забронированы". "К услугам" возвращает в каталог и очищает корзину.

## Тема

Плавающая кнопка "Тема" справа внизу: пресеты акцента, свой цвет, фон шапки (тёмный, по акценту, свой цвет или фото из `public/img/`), панель шапки (стекло, тёмное стекло, акцент, белая или свой цвет - для светлых панелей текст и пилюли сами становятся тёмными) и ползунок скруглений (0 - квадратные углы, 1 - как в дизайне, 2 - круглее). Поверх фото в шапке ложится затемняющий градиент. Значения живут в CSS-переменных `--accent` и `--rs` в `src/styles.css`; hover, подложки и нейтральные поверхности (фон страницы, чипсы, линии - 4-5 % акцента) считаются через `color-mix`. Выбор сохраняется в localStorage.

## Структура

- `src/data.ts` - услуги, категории, слоты, демо-бронирование.
- `src/cart.ts` - расчёт позиции (гости, часы, цена) и подписи.
- `src/validateCustomer.ts` - валидация формы заказчика.
- `src/Catalog.tsx`, `ServiceSheet.tsx`, `CartSheet.tsx`, `CustomerForm.tsx`, `AddedToast.tsx`, `PendingPage.tsx`, `CompletePage.tsx` - экраны.
- `src/Dialog.tsx` - bottom-sheet на телефоне и модалка на десктопе.
- `src/Header.tsx` - стеклянная шапка и слот логотипа (пилюля / круг / текст).
- `src/ThemePanel.tsx` - переключатель темы (инструмент прототипа, не часть дизайна).
- `src/styles.css` - токены, мобильные стили и десктопная media-ветка.
- `public/img/` - картинки из ассетов холста.
